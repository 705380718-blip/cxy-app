# cxy-app

个人应用项目合集。

## Projects

### AI Project Manager MVP

路径：`ai-project-manager-mvp/`

本地可用的 AI 项目经理助手 MVP，包含项目管理、任务进度、风险成本、信息归集、智能文档中心、模型配置和右侧 AI 助手。

启动方式见 `ai-project-manager-mvp/README.md`。

### City Traffic Master Visual

路径：`city-traffic-master-visual/`

《城市交通大师》Web/PWA 视觉原型，面向 iPad 横屏的城市交通沙盒体验，包含道路、车辆、公交站、公交路线、城市体检、存档和 Netlify 云同步函数。

常用命令：

```bash
cd city-traffic-master-visual
npm install
npm run dev
npm test
npm run build
```

### Geometry App

路径：`geometry-app/`

儿童几何学习小应用，支持 2D/3D 图形创建、公式计算、知识卡片、互动练习、图形对比、尺寸标注和 iPad/电脑视角操作。

验证方式：

```bash
cd geometry-app
node --test tests/geometry-app.test.mjs
```
