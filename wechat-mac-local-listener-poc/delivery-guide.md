# 交付小助手使用说明（0.5.7）

这是本机运行的交付跟进原型。消息可通过 TXT/CSV 手动导入；规则提取、手动事项、人工复核、跟进报告、评测与导出无需模型 Key。AI 分析调用已配置的 DeepSeek 云端接口，默认关闭。构造演示不代表真实识别质量或岗位收益。

## 启动与停止

离线 ZIP 适用于 macOS Apple Silicon，需本机已安装 Python 3.11；Python 解释器本身没有打进包。包含依赖 wheels，首次启动会在解压目录创建 `.venv`，离线安装固定版本，不读取旧项目环境。把 ZIP 解压到可写目录，双击 `start-delivery.command`，或执行：

```bash
bash ./start-delivery.sh
```

打开终端显示的地址，默认 `http://127.0.0.1:8792/`。按 Ctrl+C 停止。端口已占用会明确失败，可运行 `WML_PORT=8794 bash ./start-delivery.sh`；不会终止占用者。5173/8000 保留，启动器拒绝使用。已有源码开发环境仍可用 `bash ./start-delivery-dev.sh`；开发版与 ZIP 的数据库路径分别隔离。

ZIP 默认数据存于解压目录 `runtime/data/delivery.db`，不读取微信原库；采集需要另外验证客户端构建，不是导入流程的前提。2026-10-10 已在本机 Mac 微信 4.1.13（269629）完成指定群历史、增量、@昵称和重启去重检查。开发目录的私有 `.env.delivery-live` 保存该机器的采集配置，`start-delivery-dev.sh` 默认优先读取它，也可通过 `WML_ENV_FILE` 显式指定配置。

分发包包含副本解码脚本，不包含密钥、聊天记录或本机采集配置，默认采集仍关闭。其他机器应独立验证账号密钥、数据库格式和版本，验证后配置解码命令；公共最大已验证版本默认仍为 4.1.12。Windows 构建尚未完成真机解码验证。

## 按五步完成整理

1. **微信与群聊**：使用本机微信客户端登录的账号，选择或新建整理空间，填写群完整名称和自己的微信昵称。选择本机采集或手动导入，保存后自动绑定来源。
2. **采集规则**：配置关键词、关注人员、@我规则和消息保留天数，保存后进入采集。规则用于标记重点问题，AI 可进一步整理采集的群消息。
3. **开始采集**：环境具备解析条件时点击“开始采集”。无法解析时点击“改用手动导入”，选择 TXT/CSV，先预览再确认。有坏行时明确是否只接纳有效行；同份文件重复导入不会新增重复消息。页面显示当前空间消息数和最近 8 条记录。
4. **AI 分析**：通过右上角“设置”填入模型配置并启用；选择来源，点击“预览并分析消息”，核对文本并同意才开始。消息预览在侧栏每页 8 条；待复核建议每页 5 条，可按类型筛选，打开复核侧栏核对完整进展与原文后采纳；手动建事项和自动分析后续消息是折叠选项。
5. **信息与报告**：查看采纳的事项，修改责任人、期限和进展，人工更新处理状态。已确认卡片右上角“删除”可撤回；切换“显示事项 → 已撤回”可恢复。撤回不删除原文，不进入新报告；旧报告保留当时快照。展开“生成跟进报告与导出”，选择日期生成报告。确认识别正确不等于业务完成，只有人工标记“已解决”才代表完成。

顶部仅保留五步流程和模型设置，跟进报告在“信息与报告”生成与导出。群名修改不会搬移旧消息，移除名单会停止处理该群；跨空间冲突会阻止保存。切换空间后，导入、分析与报告自动跟随当前空间，同来源重复事项仍可人工合并。

TXT 示例是构造资料：

```text
[2026-10-10 09:00:00] 构造客户甲: 验收材料缺拓扑，请补充。
[2026-10-10 09:01:00] 构造同事甲: 我负责，明天 12:00 提交。
[2026-10-10 09:02:00] 构造同事甲: 拓扑已上传，等待复核。
```

CSV UTF-8 表头：`source_message_id,timestamp,sender,content`。可添加引用列；导入限 2 MiB/2000 行。消息保留窗口默认 7 天，可在规则页调整；使用旧日期演示前应核对窗口。

## AI 分析

点击任意步骤右上角“设置”，本机输入 Key 并保存，界面只回显是否已配置；勿把 Key 发到聊天、截图或导出文件。先做构造连接测试。启用后在工作台预览实际待上传的脱敏文本，核对项目/来源/范围并勾选同意才入队。每批最多 80 条，可调低；继续预览下一批直到范围处理完。规则脱敏不能保证移除所有业务机密。

“查看分析队列”打开独立侧栏，可查看失败、取消、重试；每任务累计最多三次请求，所有请求计入每日预算。格式纠正也计入次数。失败不会伪造成功结果。新版任务只接受明确请求/安排/承诺及可核对的行动原文，普通询问、事实描述、取消与已完成工作不应生成新待办。责任人或期限未知不等于没有任务；“等待结果”也不能凭空当作任务。原文规则校验较保守，可能漏掉不常见表达，仍需人工核对。已有旧批次建议保留，新标准在重新预览确认后的分析生效。待复核建议支持逐条勾选和“全选当前页”，翻页保留选择，每批最多 100 条；切换建议类型或整理空间会清空选择。点击“批量采纳”或“批量忽略”，在侧栏集中核对选中内容和原文后确认。新建议作为新事项，进展建议更新绑定事项；需要手动关联的建议仍应单独复核。处理结果显示成功/失败数与原因，失败项保留选择，依据过期或版本冲突不会覆盖旧事项。建议必须查看原文后采纳；进展更新可关联同来源已有事项。模型不能自动关闭事项。按来源自动分析需要单独同意，只覆盖启用后的新入库消息；关闭全局 AI 暂停排队，运行任务可单独取消。

## 报告与导出

在“信息与报告”展开报告入口，选择日期，生成当前事项快照。日期按北京时间，含结束日；报告不还原历史时点状态。未关闭事项可带跨期依据，已解决事项只在区间内有依据时出现。已确认、待复核和未采纳建议单列；失败/取消/未成功分析消息数随报告保存。

重复生成相同状态返回同一报告，消息、队列或事项变化会产生新版本。下载 Markdown 或 CSV；CSV 包含事项、依据、覆盖与待采纳建议。人物/来源使用代号，常见敏感字段规则脱敏，CSV 公式与 Markdown HTML 均处理。发布前仍须人工检查正文。

默认留存清理会删除过期消息、关联模型结果，并使报告/评测缓存失效。已下载的文件和迁移备份不会自动删除，需由持有人按用途清理。备份位于数据库同级 `backups/`，目录 700/文件 600；密钥配置在同级 `private/`，不在分发包内。

## 评测

效果评测已移出用户界面。开发验收可通过离线评测脚本和评测 API 完成；已有评测记录仍保留在本机。

字段核对必须逐项看责任人、期限和进展的原文依据，只有该候选全部已填字段确有依据才选“所有均有据”；空字段不计分母。用时空白表示未知，0 表示实际记录为零。填写熟悉样本偏差，确认后保存并导出 CSV；导出含指标分子/分母、人工标注、候选、消息范围与批次。

真实质量目标需 30–50 个独立人工标注事项，精确率 ≥85%、召回率 ≥80%、字段有据率 100%；至少 20 个成功且无重试的真实批次才判断 P95≤45 秒。界面仅判断统计条件是否满足，不替代参与者确认真实来源与正确性。

开发目录可重现构造评测：

```bash
.venv/bin/python scripts/evaluate-ai.py --mode rules --output output/evaluation-rules
.venv/bin/python scripts/evaluate-ai.py --mode mock --output output/evaluation-mock
.venv/bin/python scripts/serve-offline-delivery-demo.py --port 8793
```

mock 直接返回构造标签，仅验证链路。真实 CLI 必须另外设置环境变量 `DEEPSEEK_API_KEY` 并显式传 `--consent-deepseek`，未提供人工复核时质量指标保持空值；本次交付未执行真实调用。

## 备份恢复

停止服务；保留当前库副本，再将选定备份复制到原数据库路径，删除该路径旧 WAL/SHM 后启动。备份可能属于旧 schema，程序会再次迁移；不能降级使用旧程序读新库。恢复时同时遵守原有留存规则，备份可能包含已过期消息，应先确认使用权限。清理数据前先停止服务，仅清理本工具运行目录，不涉及微信库。

参赛事实与演示顺序见 `case-notes.md`；包内 `manifest.json` 记录所有文件 SHA-256，可由验证脚本核对。

## 自动整理模式

在“采集规则”勾选“自动整理并更新结果”，同意本空间后续脱敏文本发送至 DeepSeek，保存一次即可。模型未配置时会等待；在右上角设置中保存 Key 并启用 AI 后自动继续。开始采集或导入后，新消息直接进入“信息与报告”，无需逐批选择范围或逐条采纳。

从启用时当前最后消息之后开始，已有历史和既有建议保持原状，可在 AI 分析的“手动分析历史消息”中另行处理。自动结果标为“AI 自动整理”，责任人和期限可仍为未知；不等同于人工确认或业务完成。手动修改、确认、合并或恢复后的事项不会被自动覆盖，相关进展留在建议中。支持撤回恢复、原文依据及报告导出。

取消自动整理并保存规则会停止该空间新增自动任务，并取消尚在排队或执行中的自动结果任务；已经发出的模型请求无法撤回。已保存结果保留。失败、预算上限和人工冲突会显示状态。应用需保持运行，关闭应用期间不持续采集。
